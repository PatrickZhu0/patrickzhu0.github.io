Git 常用命令速查

在已有的 Git 仓库里，检查改动、提交并推送一篇文章。

1. 查看改动

打开终端并进入仓库目录。git status 显示分支和改动状态。git diff 显示 Git 已跟踪文件中尚未暂存的改动。首次创建的文件会出现在状态列表里。

git status
git diff

2. 暂存并提交

把示例里的 first-post.html 换成本次要提交的文件名。提交前用 git diff --staged 核对本次提交的内容，也能看到刚暂存的新文件。

git add first-post.html
git diff --staged
git commit -m "添加第一篇文章"

3. 推送并查看记录

如果当前分支已关联远端分支，运行 git push 即可。首次推送时，可以用下面的命令建立关联，将 main 换成当前分支名，将 origin 换成实际的远端名称。

git push -u origin main
git log --oneline -5

git log 在这里显示最近五条本地提交。如果仓库启用了 GitHub Pages，推送后可在 GitHub 仓库的 Actions 页面查看部署状态。
